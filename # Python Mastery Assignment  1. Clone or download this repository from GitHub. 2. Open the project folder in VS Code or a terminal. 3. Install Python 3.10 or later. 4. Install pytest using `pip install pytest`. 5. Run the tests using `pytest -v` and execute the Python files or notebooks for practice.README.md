# Python Mastery Assignment

This repository contains Python practice exercises and assignments covering fundamental and intermediate Python concepts.

## Topics Covered
- Variables, data types, and conditional statements
- Loops, lists, dictionaries, and mutability
- Functions, modules, and exception handling
- Object-Oriented Programming (OOP)
- Iterators, generators, and file handling
- Unit testing with pytest

## Requirements
- Python 3.10 or later
- Jupyter Notebook (for `.ipynb` files)
- pytest

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/pkashafzeb-cpu/PythonMastery_Assignment.git
   ```
2. Open the project directory:
   ```bash
   cd PythonMastery_Assignment
   ```
3. Install pytest:
   ```bash
   pip install pytest
   ```
4. Run the tests:
   ```bash
   pytest -v
   ```
5. Open the Python files or notebooks to explore and execute the exercises.
